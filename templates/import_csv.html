CSV 格式说明

首行为表头，至少需要 instance_id 列。导出的 CSV 可直接导入。

列名 必填 说明
instance_id 是 ECS 实例 ID
name 否 实例名称（默认使用 instance_id）
region_id 否 地域（默认 cn-hangzhou）
access_key_id 否 AK（需与 SK 同时提供）
access_key_secret 否 SK（需与 AK 同时提供）
tag 否 标签分组
notes 否 备注信息
traffic_strategy 否 cycle（按月） / life（生命周期）
monthly_limit 否 月流量限额 (GB)
life_total_limit 否 总流量限额 (GB)
monthly_free_allowance 否 月免费额度 (GB)，默认 200
alert_threshold_pct 否 告警阈值 (%)，默认 80
auto_stop_enabled 否 超额自动关机 (true/false)
auto_start_enabled 否 自动开机 (true/false)

CSV 示例：

name,instance_id,region_id,access_key_id,access_key_secret,tag,traffic_strategy,monthly_limit
web-01,i-abc123,cn-hangzhou,LTAI...,abcdef,项目A,cycle,500
web-02,i-def456,cn-shanghai,LTAI...,ghijkl,项目B,life,1000
