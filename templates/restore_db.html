从数据库导入实例

上传 SQLite 数据库文件，自动导入其中的实例信息到当前面板。

导入说明
  • 仅导入实例数据（AK/SK、流量、配置等），不会更改面板密码
  • 已有的实例（相同 Instance ID）会被更新，新实例会被添加
  • 支持 Python 版和 Go 版的数据库备份文件
  • Python 版数据库的 AK/SK 会自动转换加密格式（需提供旧密钥）
