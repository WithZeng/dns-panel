帮助中心

功能说明与常见问题

查看实例详情

在仪表盘页面点击任意实例卡片即可进入实例详情页。详情页展示以下信息：

  • 实例基本信息（名称、IP 地址、区域、规格等）
  • 实时运行状态
  • 流量使用情况与趋势图表
  • 告警阈值配置
管理安全组规则（端口）

在实例详情页点击「安全组」按钮进入安全组管理页面，您可以：

  • 添加规则 — 指定端口范围、协议（TCP/UDP）和授权 IP 段来开放端口
  • 删除规则 — 移除不再需要的安全组规则
  • 常用端口快捷添加：SSH (22)、HTTP (80)、HTTPS (443) 等

注意：修改安全组规则会立即生效，请谨慎操作。

使用 VNC 远程连接

在实例详情页点击「VNC」按钮，系统将生成一个临时 VNC 连接链接并在新窗口中打开。

  • VNC 连接链接有效期较短，过期后需重新获取
  • 通过 VNC 可以直接操作实例的控制台，适用于 SSH 无法连接时的紧急维护
  • 建议使用 Chrome 或 Firefox 浏览器以获得最佳体验
重装系统

在实例详情页点击「重装系统」按钮，选择目标镜像后确认即可开始重装。

  • 重装系统会清除实例上的所有数据，请提前备份重要文件
  • 重装过程中实例将暂时不可用，通常需要 3-10 分钟
  • 重装完成后需要重新设置密码才能登录

警告：此操作不可逆，请确认已备份所有重要数据。

修改备注与告警阈值
  • 修改备注 — 在实例详情页的备注区域直接编辑，用于标记实例用途或其他说明
  • 告警阈值 — 在流量设置中调整告警百分比，当流量使用达到该比例时触发告警通知

常见问题

为什么我无法启动或停止实例？
实例的启动、停止和重启操作仅限管理员执行。如果您需要进行这些操作，请联系管理员。
为什么我看不到某些实例？
普通用户只能查看管理员分配给您的实例。如果您需要访问其他实例，请联系管理员进行授权。
流量告警是如何触发的？
当实例的流量使用量达到设定的告警阈值百分比时，系统会通过 Telegram Bot 发送通知。您可以在实例详情页的流量设置中调整告警阈值。
如何修改登录密码？
点击左下角用户头像，在弹出菜单中选择「修改密码」。输入当前密码和新密码后提交即可。新密码至少需要 6 个字符。
VNC 连接打不开怎么办？
  • 确认实例处于「运行中」状态
  • 检查浏览器是否阻止了弹出窗口
  • VNC 链接有效期较短，如果超时请重新点击「VNC」按钮获取新链接
  • 建议使用 Chrome 或 Firefox 浏览器
